# Instalação — Executor_altGRID_consenso

Esta pasta já está no formato de Agent Skill: `SKILL.md` obrigatório + `references/` e `assets/` opcionais.

Para uso específico do repositório no Codex, copie a pasta inteira para:

```text
<REPO_ROOT>/.agents/skills/Executor_altGRID_consenso/
```

Para uso global do usuário:

```text
$HOME/.agents/skills/Executor_altGRID_consenso/
```

No Codex CLI, a skill pode ser selecionada via `/skills` ou mencionada explicitamente pelo nome da skill.
